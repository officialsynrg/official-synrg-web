# SYNRG Website

Website landing page modern untuk grup musik/creative collective SYNRG, dibangun dengan React, TypeScript, dan Vite. Proyek ini menampilkan identitas visual yang kuat, pengalaman musik interaktif, serta informasi lengkap tentang anggota, karya, pencapaian, dan kontak.

## Tentang Proyek

SYNRG adalah presentasi digital yang menggabungkan estetika futuristik, nuansa gelap, dan pengalaman audio yang imersif. Situs ini dibuat sebagai single-page experience yang terasa premium, elegan, dan sesuai dengan brand artistik SYNRG.

## Fitur Utama

- Hero section dengan branding yang kuat
- Halaman anggota dengan profil, peran, dan estetika masing-masing
- Section discography untuk menampilkan lagu dan cover
- Galeri pencapaian dan penghargaan
- Story/about section yang menjelaskan visi grup
- Section news untuk update terbaru
- Contact section untuk koneksi dan informasi
- Music player floating yang memungkinkan pemutaran lagu interaktif

## Teknologi yang Digunakan

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Motion untuk animasi
- Lucide React untuk ikon

## Menjalankan Secara Lokal

Pastikan Node.js sudah terinstal di sistem Anda.

1. Instal dependensi:
   `npm install`
2. Jalankan development server:
   `npm run dev`
3. Buka browser di:
   `http://localhost:3000`

## Build untuk Produksi

Untuk membuat versi production:

```bash
npm run build
```

## Struktur Folder

- `src/components` — komponen UI website
- `src/data.ts` — konten utama seperti anggota, lagu, galeri, dan berita
- `src/types.ts` — definisi tipe data
- `assets` — gambar, audio, dan media pendukung

## Catatan

Proyek ini dirancang sebagai website presentasi untuk identitas digital SYNRG, bukan template umum, sehingga isi kontennya dibuat khusus agar sesuai dengan nuansa dan cerita grup.
